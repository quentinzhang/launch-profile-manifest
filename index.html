Launch Operations Protocol is a launch coordination protocol suite. Its core profile layer is Launch Profile Manifest (LPM), paired with Release Envelope and Browser Task records.

View profile schema Read on GitHub

Status: v0.1 is an early draft schema and reference implementation, not an industry standard.

01

Profile

Stable identity, positioning, audience, offers, assets, claims, and provenance.

02

Release

A launch, relaunch, major release, integration, market entry, or distribution wave.

03

Browser Task

A self-contained handoff that a compatible runner can open and prefill while final submission stays human-controlled.
